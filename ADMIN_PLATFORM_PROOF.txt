AUTH (replaces ADMIN_SECRET)
  - admin_users table (PostgreSQL)
  - bcrypt password hashes (cost 12)
  - JWT admin_access tokens (15m default) + refresh tokens (7d, stored hashed)
  - CSRF token required on all mutating admin routes (X-CSRF-Token header)
  - Roles: super_admin, support, compliance, read_only
  - Bootstrap: ADMIN_BOOTSTRAP_EMAIL + ADMIN_BOOTSTRAP_PASSWORD on first deploy
  - Optional 2FA: schema hook ready (twoFactorEnabled in login response; UI not yet)
